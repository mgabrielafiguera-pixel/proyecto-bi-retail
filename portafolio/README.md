# Portafolio

Sitio estático del portafolio (HTML y CSS, sin dependencias). Abre `index.html` en el navegador para verlo.

- `index.html`: inicio con experiencia, proyectos, habilidades y formación.
- `proyecto-01.html`: caso Sell In / Sell Out, con video, capturas, hallazgos y límites.
- `proyecto-07.html`: resultado por tienda, tendencia y estacionalidad, con video de presentación (70 s).
- `img/`: capturas del informe de Power BI, solo con códigos anonimizados.
- `video/`: recorrido del informe (59 s) y presentación de resultados por tienda (70 s), ambos sin audio.

Se publicará en GitHub Pages cuando el repo pase a público. Cada proyecto nuevo agrega su página y su tarjeta en el inicio.
Pendiente: el botón del PDF del informe.
